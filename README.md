# FORGE CLI

**FORGE CLI** is an intelligent, terminal-based AI pair programmer designed to streamline the software development lifecycle. Powered by **Google Gemini 2.0 Flash**, it employs a multi-agent architecture to help developers efficiently plan, architect, and review code changes directly from the command line.

## 🚀 Features

*   **Multi-Agent Workflow**: Specialized agents collaborate to break down complex tasks:
    *   **🧱 Creator Agent**: Decomposes high-level goals into clear, actionable phases with defined acceptance criteria.
    *   **🗂️ Planner Agent**: Generates precise, file-by-file implementation plans for each phase.
    *   **🧐 Reviewer Agent**: Audits plans for potential risks, conflicts, and missing dependencies before you write a single line of code.
*   **Context-Aware**: Smartly injects file contexts into the AI's "brain" using `@filename` syntax (e.g., "Check logic in @src/main.ts").
*   **Local Codebase Indexing**: automatically indexes your project files to enable semantic understanding and fuzzy search without uploading your entire repo.
*   **Terminal UI**: A rich, interactive command-line interface built with `chalk` for clear readability and structured interaction.

## 🛠️ Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/yourusername/codex-cli.git
    cd codex-cli
    ```

2.  **Install tools & dependencies**
    ```bash
    npm install
    # Ensure you have TypeScript installed globally or use npx
    ```

3.  **Environment Configuration**
    Create a `.env` file in the root directory and add your Google Gemini API key:
    ```env
    GOOGLE_API_KEY=your_gemini_api_key_here
    ```

## 💻 Usage

To start the CLI, run:

```bash
npm start
```

You will be presented with a menu to choose your mode:

### 1. 🧱 Creator Mode
High-level architecting. Describe your goal (e.g., "Add a user authentication system"), and the Creator will break it down into sequential phases with file paths and dependencies.

### 2. 🗂️ Planner Mode
Tactical planning. Paste a specific phase from the Creator's output. The Planner will generate a detailed list of every file that needs to be created or modified, including the specific changes required.

### 3. 🧐 Reviewer Mode
Quality assurance. Paste a plan generated by the Planner. The Reviewer will analyze it for edge cases, security risks, or architectural inconsistencies.

## 🏗️ Technical Stack

*   **Language**: TypeScript / Node.js
*   **AI Model**: Google Gemini 2.0 Flash (`@google/generative-ai`)
*   **File System**: `fs-extra`, `glob`
*   **Search**: `fuse.js` (Fuzzy logic)
*   **CLI UX**: `chalk`, `readline`
